# Lil Wooski: retired

The generative soundtrack (`Music.ts`, `Score.ts`, `LiveVibe.ts`, `Busker.ts`, `Critique.ts`, `inspo.json`) was removed on request: the world has no background music now. What you hear is the world itself (Hunter's footsteps, cars, weather, doors, the party beat by the stage) plus the MosaicScope FM radio, which only plays when you press ▶.

If a scheduled "Lil Wooski: composer" routine still exists, it should be turned off: there is no score left for it to work on.
